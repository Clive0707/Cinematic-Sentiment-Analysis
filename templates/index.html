System Architecture

About the Models

Technical details of the classification pipelines and NLP feature extraction.

Primary Supervised Classifier

Multinomial Naive Bayes

Used as the primary supervised classification algorithm. Multinomial Naive Bayes calculates class probabilities using Bayes' theorem assuming feature independence. It is highly efficient for text classification with TF-IDF features.

Secondary Supervised Classifier

Logistic Regression

Used as a second supervised classification algorithm for comparison. Logistic Regression models the probability of binary outcomes using a sigmoid function over a linear combination of TF-IDF feature weights.

Feature Extraction

TF-IDF Vectorizer

Converts Marathi text into numerical features for machine learning. TF-IDF evaluates word frequency in a review relative to word distribution across the dataset to weight key sentiment-bearing terms.

NLP Feature

Cosine Similarity

Measures similarity between the TF-IDF representation of the user's review and reviews in the dataset. Retrieves the top 3 dataset matches for contextual review comparison.
